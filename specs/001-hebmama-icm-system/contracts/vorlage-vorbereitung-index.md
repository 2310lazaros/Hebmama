# Vorbereitung

> **Orientierung.** HebMama ist eine Orientierungshilfe. Sie ersetzt weder den persönlichen ärztlichen Rat noch das Gelbe Heft noch den griechischen Gesundheitsnachweis. Bei akuten Beschwerden wenden Sie sich an eine Ärztin, einen Arzt oder den Notruf. [Ausführlich](../hinweise/orientierung.md)

## Zweck

Jedes Paket enthält einen Leitfaden, eine Checkliste und eine Fragenliste für einen benannten Kontakt.

## Rahmen

Deutsche Pakete folgen den zehn Untersuchungen. WHO-Pakete folgen den abgelegten Postnatalkontakten. Ein griechisches Paket gibt es erst mit einem benannten griechischen Kontakt. Bis dahin führt der Vergleich auf die [Lücken](../hinweise/luecken.md).
