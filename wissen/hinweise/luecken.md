# Lücken

> **Orientierung.** HebMama ist eine Orientierungshilfe. Sie ersetzt weder den persönlichen ärztlichen Rat noch das Gelbe Heft noch den griechischen Gesundheitsnachweis. Bei akuten Beschwerden wenden Sie sich an eine Ärztin, einen Arzt oder den Notruf. [Ausführlich](orientierung.md)

## Zweck

Hier stehen Themen im Rahmen, für die noch keine ausreichende amtliche Quelle abgelegt ist. Eine Lücke ist kein Platz für eine eigene medizinische Festlegung.

## Rahmen

Neue Lücken bekommen die nächste freie Kennung. Geschlossene Lücken bleiben mit ihrem Abschnitt stehen.
